# Шичой — Windows-версия (C++20 + raylib)

Бесконечный аркадный рогалик: тёмный оверворлд сверху + пошаговые карточные бои
от первого лица. Протагонист — мрачный аристократ-маг во фраке и цилиндре.
Ни одного платного или скачанного ассета: **и графика, и звук делаются кодом**.

---

## Почему такой стек

| Решение | Причина |
|---|---|
| **C++20** | Требование «по возможности C++». Никакого рантайма, один .exe. |
| **raylib 5.5** | Даёт ровно то, чего не хватает голому C++: окно, ввод, 2D-рендер, шрифты, звук. Zlib-лицензия, бесплатна, статически линкуется — на выходе один самодостаточный .exe. Альтернативы: SDL2 (ниже уровнем, больше кода), Unity/Godot (не C++). |
| **MSVC + CMake + Ninja** | Уже стоят вместе с Visual Studio 2022, отдельно ставить нечего. |
| **Процедурная графика** | Прямой ответ на проблему с артом: Grok даёт плохой результат, рисовать не умеешь, покупать не хочешь. Здесь спрайтов просто нет — рамки Таро, сигилы 16 стихий, фигура героя, силуэты врагов и тайлы собираются из примитивов по палитре и сиду. |
| **Процедурный звук** | Тот же приём, что и с графикой: ни одного аудиофайла. Эффекты синтезируются в память при старте, музыка генерируется прямо в колбэке аудиопотока и поэтому не зацикливается. |
| **Системный шрифт Windows** | Кириллица берётся из `C:\Windows\Fonts` (Segoe UI + Georgia). Ничего не поставляется, ничего не лицензируется. Если шрифт не найден — игра сама переключается на английский. |

## Сборка и запуск

```bash
build.bat
```

Скрипт сам находит Visual Studio через `vswhere`, поднимает `vcvars64`,
конфигурирует CMake и собирает. Результат: `build\bin\Shichoy.exe`.

```bash
run.bat
```

Собрать и сразу запустить. Отладочная сборка — `build.bat Debug`.

raylib лежит в `external/raylib` (клон тега 5.5). Если папку удалить, CMake
скачает её сам через `FetchContent` при первой конфигурации.

Служебные режимы:

```bash
build\bin\Shichoy.exe --selftest
```

прогоняет 180 боёв на глубинах 1–15 и 200 операций крафта без окна: ловит
зависания, проверяет, что все 120 пар стихий дают реакцию и что потолок
шанса крафта не пробит.

```bash
build\bin\Shichoy.exe --shot
```

сохраняет по кадру с каждой сцены рядом с .exe.

```bash
build\bin\Shichoy.exe --audiodump
```

синтезирует все звуки и по куску каждого трека в .wav рядом и печатает пик/RMS
по каждому — так проверяется, что ничего не клиппит и ничего не молчит.

## Работа с другого компьютера

Весь проект лежит в репозитории, поэтому домашний компьютер для работы не
нужен — он может быть выключен.

На ноутбуке один раз:

```
git clone https://github.com/shikagera/Kartovasiya.git
cd Kartovasiya
git checkout claude/arcade-roguelike-card-battle-e2bdad
```

Чтобы собрать, нужны те же две вещи, что и на домашней машине: **Visual Studio
2022** с рабочей нагрузкой «Разработка классических приложений на C++» (она
приносит и компилятор, и CMake, и Ninja) и **Git**. Больше ничего ставить не
надо: raylib лежит в `external/` прямо в репозитории, внешних ассетов у игры
нет вовсе. Дальше как обычно — `proekti\windows\Shichoyuild.bat`.

Закончив работу на ноутбуке, отправьте сделанное обратно:

```
git add -A
git commit -m "что сделано"
git push
```

А дома перед началом заберите:

```
git pull
```

Ветка `claude/arcade-roguelike-card-battle-e2bdad` — рабочая, вся разработка
идёт в ней. В `main` она пока не влита.


## Управление

**Оверворлд:** `WASD` — идти · `E` — взаимодействие · `C` — верстак ·
`K` — кодекс стихий · `ESC` — уехать (закончить забег и сохранить добытое).

**Везде:** `P` — пауза с громкостью и выходом · `M` — выключить/включить звук.

**Бой:** карты **перетаскиваются мышью**. Тянешь карту вверх, за линию стола, и
отпускаешь — она играется. Бросишь карту **прямо на другую карту в руке** — они сольются по лестнице
уровней; над рукой всплывает табличка с тем, что получится, или с причиной
отказа. Бросишь в промежуток между картами — просто переставится
(в ряду показывается щель «сюда»). Правый клик по ходу перетаскивания отменяет.
Клавиши: `1…9` — сыграть карту без мыши · `TAB` — переключить точку ·
`Q` — сбросить прицел на корпус · `ENTER` / `SPACE` — конец хода ·
`F` — сбежать (теряется четверть материалов).

**Верстак:** клик по карте — выбрать цель · `ESC` — закрыть. Каждая работа
разыгрывается случайной мини-игрой, у каждой своё управление — подсказка висит
над игровым полем.

## Мини-игры

Семь коротких испытаний в духе «Dumb Ways to Die»: каждое длится несколько
секунд, у каждого свой орган управления, и исход всегда один из трёх —
провал, успех, безупречно. Они решают крафт, вскрытие тайников и рискованные
события. «Шанс» из плана работы задаёт снисходительность: ширину зоны, запас
времени, длину последовательности.

| Игра | Что делаешь |
|---|---|
| Верный удар | остановить бегунок в зелёной полосе (`SPACE`) |
| Сургучная печать | зажать кнопку и вести печать вправо ровным темпом |
| Твёрдая рука | провести курсор по извилистому коридору, не задев стенок |
| Задуть свечи | чередовать `A` и `D`, раздувая мех |
| Миг | ударить `SPACE` ровно на вспышке; фальстарт — провал |
| Наизусть | запомнить порядок вспышек и повторить цифрами `1…4` |
| Шифр | найти показанную руну в решётке похожих и щёлкнуть по ней |

## Нисхождение, разблокировки, реликвии

**Нисхождение** — лестница сложности на 20 ступеней. Каждая добавляет ровно
одно правило, и все нижние продолжают действовать. Правила нарочно разного
рода: часть давит числами (урон, здоровье врага, трофеи), часть отнимает
инструменты (слот хода, карту добора, возможность сбежать, потолок крафта).
Ступень выбирается в меню стрелками и засчитывается только за живой уход с
глубины от пятой.

**Реликвии** — 103 штуки. Они устроены данными, а не ветками в коде: RelicDef
несёт числовые поля, они складываются в RelicMods, и бой читает уже сумму.
Эффекты, которые числом не выражаются, помечены `RelicSpecial` и ищутся по
признаку — поэтому несколько разных реликвий могут нести один и тот же
особый эффект.

**Разблокировки** — битовая маска в мете. Веха (глубина, собранная
библиотека, пройденная ступень) ставит бит, бит открывает пласт реликвий.
Стартовый пул — 25 из 103.

## Местности и путешествие

Важно не путать два понятия. **Биом** (`core/Biome.h`) — это тайл под ногами,
он решает исход конкретного боя. **Местность** (`world/Locale.h`) — целый
регион со своей палитрой земли, своей флорой и своими правилами заселения.
Между местностями герой путешествует на развилке.

| Местность | Чем узнаётся |
|---|---|
| Старый лес | дубы с тёмным контуром, папоротник, валежник — стартовая местность |
| Снежник | наст, ели ярусами под снежными шапками, холодная палитра |
| Побережье | песок, пальмы с веером листьев и кокосами, бирюзовая вода |
| Джунгли | широкий тёмный полог, лианы, насыщенная зелень |
| Усадьба | дом героя: стриженые изгороди, врагов нет, карета у крыльца |

Силуэт дерева и делает местность узнаваемой с первого взгляда, поэтому
`TreeStyle` правит не только цвет, но и пропорции ствола.

Усадьба пока нарочно пустая — это задел. Единственное, что она делает:
лечит на треть и не даёт глубины. Карета там не заканчивает забег, а
возвращает на развилку, иначе из собственного дома нельзя было бы выехать,
не бросив всё добытое.

## Спуск и боссы

Спуск на глубину всегда проходит через **развилку**: три местности с
объявленной опасностью (тихо / опасно / гибельно) и объявленной наградой в
конце пути, плюс всегда доступный заезд в усадьбу.
Опасность решает, насколько густо в новом регионе враги, награда выдаётся
сразу. Реликвия закреплена за гибельным маршрутом, остальные боны между собой
не повторяются.

**Боссов двенадцать**, и каждый именной: свой облик и стихия, свои реплики на
смене фаз и фирменный приём, который кладётся в последнюю фазу, — бой
запоминается концом. Кто именно встретится, зависит от глубины: у каждого
есть `minDepth`, раньше которой он не появляется.

## Что уже работает

**Оверворлд.** Процедурный регион 96×96 тайлов на двух слоях шума: трава, гниль,
вода, топь, камни, деревья, терновник, могилы, протоптанные тропы. Ресурсные
узлы (8 материалов), три типа NPC, площадки событий, ворота руин с боссом,
карета для выхода из забега. Бродячие враги патрулируют и переходят в
преследование в радиусе видимости — контакт запускает бой. Чем глубже регион,
тем больше порчи, врагов и их скорость.

Кроме того на карте живут: **костры** (погреться на +35% HP или бесплатно
перековать карту в огне), **запертые тайники** (замок открывается конкретной
мини-игрой — жилами, твёрдой рукой или печатью) и **алтари без имени**
(отдать 12 материалов или 12 HP за +8 к максимуму HP, +1 слот хода или
+1 к добору до конца забега).

**Биомы.** Тайл под ногами решает, где именно принят бой: Луг, Гниль, Топь,
Камни, Чаща, Терновник, Могильник. Каждый усиливает две свои стихии на 30–35%.
Биом виден в оверворлде заранее и подписан в бою — исследование стало
подготовкой, а не просто дорогой между драками.

**Реликвии.** Одиннадцать пассивок, меняющих правила, а не числа: лишний слот
хода, первая карта за ход бесплатно, метка не спадает, эхо повторяет реакции,
нет промаха по точкам, кровный вексель (+30% урона за 2 HP с карты), скупая
ладонь и алембик (карта из руки уходит в колоду после боя), восковой двойник
(переживаешь смертельный удар), лопата могильщика. Падают с боссов
гарантированно и продаются скупщиком за 18 материалов.

**Сохранение забега.** Незаконченный забег переживает закрытие окна: колода
со всеми текстами, реликвии, статусы, инвентарь и состояние региона пишутся
в `shichoy_run.bin` каждые несколько секунд и на выходе. Сам регион
восстанавливается из сида, так что в файл идут только правки игрока. В меню
появляется «Продолжить забег»; смерть или отъезд снимок удаляют.

**Переход в бой.** При столкновении — полуторасекундная сцена: камера
схлопывается, чёрные полосы, аристократ вытаскивает из-под фрака стол,
раскладывает сукно и карты. Это единственное заимствование у Undertale —
сам переключатель режима, не bullet-hell.

**Бой.** Пошаговый, вид от первого лица. Маны нет — лимит 5 карт за ход
(тяжёлые карты стоят 2 слота, карты-эффекты лимит поднимают).

Рука между ходами **не сбрасывается**: всё несыгранное остаётся лежать, а в
начале хода сверху приходит ещё 5 карт. Потолка у руки нет, поэтому она
копится — карты в ряду ужимаются и наезжают друг на друга, а та, что под
курсором, всплывает в полный размер, чтобы её можно было прочитать.
Играются карты перетаскиванием, и тем же жестом сливаются друг с другом.

**Лестница слияния.** Карта несёт уровень и цепочку стихий, из которых собрана.
Бросок карты на карту поднимает результат по ступеням:

| Ур. | Что смешивается | Множитель | Особенность |
|---|---|---|---|
| 0 | одна стихия | x1 | вешает метку, реакция идёт через врага |
| I | стихия + стихия | x2 | каноничная реакция из таблицы пар |
| II | ур. I + новая стихия | x3 | копятся статусы всей цепи |
| II+ | ур. I + ур. I | x3.75 | пробивает щит врага |
| III | ур. II + стихия или ур. I | x5 | бьёт по корпусу и каждой точке разом |
| III+ | ур. II + ур. II | x6.5 | всё выше плюс оглушение |
| Ultima | ур. III + ур. III, 5+ стихий | x10 | +20% текущего HP, игнорирует щит, раз за бой |

Правила жёсткие: нужна стихия, которой в цепочке ещё нет; уровень III сливается
только с другим III; собранная Ultima дальше не смешивается. Мощность растёт
подлинейно (`max + min/2`), иначе цепочка из восьми карт улетала бы в космос,
а множитель берётся из таблицы, а не перемножается. Составные карты стоят
2 слота хода, Ultima — 3. Разыгранная составная карта не вешает метку, а
разряжается целиком: наносит урон и вешает статусы всех стихий своей цепи.
Лестница описана внутри игры — `K`, третья страница кодекса.

- **Element** — вешает метку стихии. Вторая Element-карта другой стихии
  триггерит реакцию и снимает метку. 16 стихий, ~50 именованных пар
  (Огонь+Вода = Пар, Эфир+Тень = Разлом пустоты…), остальные 70 пар
  разрешаются процедурно в «Смесь»/«Разлад», так что мёртвых сочетаний нет.
- **Spell** — прямое действие: урон, залп, точный удар, вытягивание, лечение,
  усиление следующей реакции, подрыв метки.
- **Effect** — немагические статусы: щит, добор, +лимит карт, стан,
  сосредоточение, очищение, ослабление, регенерация.

**Противник.** Без колоды: HP-бар, фиксированный паттерн приёмов, многофазность
(у боссов три фазы) и собственный щит. Намерение на следующий ход показано
иконкой приёма и точным числом урона под полосой здоровья — не строкой в
журнале, которую не успеваешь прочитать. Щит пробивается картами «удара сквозь
щит» и слиянием от третьего уровня.
С глубины 6 враг делает два действия за ход, с 12 — три; боссы на одно больше.

**Прицеливание** (открытый вопрос из ТЗ — решён гибридом). По умолчанию
автонаведение на корпус. `TAB`/правый клик берут конкретную точку: обычная
карта отдаёт по ней 65% урона и имеет 22% промаха, а «точные» карты
(`Pierce`, флаг `Precise` — в стартовой колоде это «Трость-шпага») бьют по
точке на 100% без промаха. Статус «Сосредоточение» убирает промах у любых карт.
Так ручное прицеливание — это осознанный риск, а отдельный тип карты — способ
его снять, без обязательного микроменеджмента.

**Прогрессия.** Материалы с врагов, боссов, ресурсных узлов и событий идут на
верстак: выковать новую процедурную карту, усилить (+уровень), мутировать
(аффикс + сдвиг чисел) или переплавить излишки. Успех решает мини-игра на
тайминг: ширина зелёной зоны равна шансу, а шанс жёстко ограничен 70% — внутри
есть узкая «идеальная» зона, она удваивает эффект. Провал мутации портит карту.
Карты генерируются процедурно: тип, стихия, числа по глубине, редкость
(6 ступеней), аффиксы и флаги Wild/Corrupted/Mutated/Precise.

**Мета-прогресс.** Уехавший на карете забег банкует все материалы и конвертирует
их в постоянный бонус к максимуму HP; смерть сохраняет только четверть.
Сохранение — `shichoy_meta.bin` рядом с .exe.

**Звук.** Ни одного аудиофайла. Шестнадцать «голосов стихий» и два десятка
эффектов синтезируются в память при старте из одной параметрической модели:
частотный свип, обертоны (от гармонических до несоизмеримых — так звучат
металл и кристалл), шум сквозь резонансный фильтр, треск, низкий подхвост.
Молния получает мгновенную атаку, резкий треск и раскат в хвосте; лёд —
звонкие несоизмеримые обертоны; земля — глухой удар с гулом. При розыгрыше
карты сперва слышен шорох бумаги, следом — голос её стихии; реакция бьёт
поверх обоих, и чем она сильнее, тем ниже её тон.

Музыка генеративная: орган, дрон, редкие колокола по пентатонике и ветер
считаются прямо в колбэке аудиопотока, поэтому трек не повторяется. Три
режима — меню, поле (почти шёпот) и бой (тише, но с низким пульсом вместо
колоколов) — переключаются по сцене с плавным переходом. `M` глушит всё.

**Языки.** Весь текст двуязычный (RU/EN), переключается в меню.

## Структура

```
src/
  core/Types.h      — enum'ы, билингвальные строки, ГПСЧ, цветовые утилиты
  core/Content.*    — 16 стихий, таблица реакций, статусы, материалы, пулы имён
  core/Cards.*      — карта, процедурная генерация, мутации, апгрейд, колода
  core/Merge.*      — лестница слияния карт в руке: правила, имена, эффекты
  audio/ProcAudio.* — синтез эффектов и генеративная музыка, тоже без файлов
  art/ProcArt.*     — палитра Таро, шрифты, шум, орнаменты, сигилы, рисование
                      карт, героя и врагов — весь визуал игры
  world/Overworld.* — генерация региона, сущности, движение, ИИ врагов, отрисовка
  combat/Enemy.*    — паттерны, фазы, именные боссы, генерация противника
  world/Locale.*    — местности: палитры земли, стили деревьев, заселённость
  combat/Combat.*   — конечный автомат боя, метки, реакции, урон, статусы, лут
  craft/Craft.*     — инвентарь, планы крафта, сжигание карт
  craft/MiniGames.* — восемь мини-игр на разных органах управления
  core/Biome.*      — биомы: место боя усиливает свои стихии
  core/Relics.*     — реликвии, меняющие правила боя
  core/Save.*       — бинарный поток и снимок забега
  app/Game.*        — сцены, переходы, диалоги, HUD, меню, кодекс
  app/GameCombatUI.cpp — интерфейс боя и экран наград
  main.cpp          — точка входа, --selftest, --shot
```

## Куда двигаться дальше

- **Арт.** Кодовая графика работает и её достаточно, чтобы играть. Если
  захочется растровых спрайтов — заводится папка `assets/` и подменяется
  вызовами `DrawTexture` в `ProcArt`; остальной код не меняется. Бесплатные
  CC0-источники под эту эстетику: Kenney.nl, OpenGameArt (метка CC0),
  itch.io с фильтром «free assets», LPC-набор.
- **Звук.** Сейчас у врагов нет собственных голосов: приёмы звучат общим
  ударом. Стоит дать каждому противнику тембр от его стихии — модель для
  этого уже есть, нужен только набор параметров на приём.
- **Контент.** Именованных реакций сейчас ~50 из 120 возможных пар; остальные
  закрыты процедурным фолбэком, их можно постепенно расписывать вручную.
- **Баланс.** `--selftest` даёт быстрый замер: сейчас случайная игра выигрывает
  ровно половину боёв на глубинах 1–15, то есть у осмысленной игры запас есть,
  а глубина всё равно наказывает.
