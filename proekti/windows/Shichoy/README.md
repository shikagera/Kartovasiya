# Шичой — Windows-версия (C++20 + raylib)

Бесконечный аркадный рогалик: тёмный оверворлд сверху + пошаговые карточные бои
от первого лица. Протагонист — мрачный аристократ-маг во фраке и цилиндре.
Ни одного платного или скачанного ассета: **и графика, и звук делаются кодом**.

---

## Почему такой стек

| Решение | Причина |
|---|---|
| **C++20** | Требование «по возможности C++». Никакого рантайма, один .exe. |
| **raylib 5.5** | Даёт ровно то, чего не хватает голому C++: окно, ввод, 2D-рендер, шрифты, звук. Zlib-лицензия, бесплатна, статически линкуется — на выходе один самодостаточный .exe. Альтернативы: SDL2 (ниже уровнем, больше кода), Unity/Godot (не C++). |
| **MSVC + CMake + Ninja** | Уже стоят вместе с Visual Studio 2022, отдельно ставить нечего. |
| **Процедурная графика** | Прямой ответ на проблему с артом: Grok даёт плохой результат, рисовать не умеешь, покупать не хочешь. Здесь спрайтов просто нет — рамки Таро, сигилы 16 стихий, фигура героя, силуэты врагов и тайлы собираются из примитивов по палитре и сиду. |
| **Процедурный звук** | Тот же приём, что и с графикой: ни одного аудиофайла. Эффекты синтезируются в память при старте, музыка генерируется прямо в колбэке аудиопотока и поэтому не зацикливается. |
| **Системный шрифт Windows** | Кириллица берётся из `C:\Windows\Fonts` (Segoe UI + Georgia). Ничего не поставляется, ничего не лицензируется. Если шрифт не найден — игра сама переключается на английский. |

## Сборка и запуск

```bash
build.bat
```

Скрипт сам находит Visual Studio через `vswhere`, поднимает `vcvars64`,
конфигурирует CMake и собирает. Результат: `build\bin\Shichoy.exe`.

```bash
run.bat
```

Собрать и сразу запустить. Отладочная сборка — `build.bat Debug`.

raylib лежит в `external/raylib` (клон тега 5.5). Если папку удалить, CMake
скачает её сам через `FetchContent` при первой конфигурации.

Служебные режимы:

```bash
build\bin\Shichoy.exe --selftest
```

прогоняет 180 боёв на глубинах 1–15 и 200 операций крафта без окна: ловит
зависания, проверяет, что все 120 пар стихий дают реакцию и что потолок
шанса крафта не пробит.

```bash
build\bin\Shichoy.exe --shot
```

сохраняет по кадру с каждой сцены рядом с .exe.

```bash
build\bin\Shichoy.exe --audiodump
```

синтезирует все звуки и по куску каждого трека в .wav рядом и печатает пик/RMS
по каждому — так проверяется, что ничего не клиппит и ничего не молчит.

## Управление

**Оверворлд:** `WASD` — идти · `E` — взаимодействие · `C` — верстак ·
`K` — кодекс стихий · `ESC` — уехать (закончить забег и сохранить добытое).

**Везде:** `M` — выключить/включить звук.

**Бой:** `1…9` или клик — сыграть карту · `TAB` — переключить уязвимую точку ·
`Q` — сбросить прицел на корпус · правый клик по точке — выбрать её ·
`ENTER` / `SPACE` — конец хода · `F` — сбежать (теряется четверть материалов).

**Верстак:** клик по карте — выбрать цель · `SPACE` / клик — остановить бегунок
мини-игры · `ESC` — закрыть.

## Что уже работает

**Оверворлд.** Процедурный регион 96×96 тайлов на двух слоях шума: трава, гниль,
вода, топь, камни, деревья, терновник, могилы, протоптанные тропы. Ресурсные
узлы (8 материалов), три типа NPC, площадки событий, ворота руин с боссом,
карета для выхода из забега. Бродячие враги патрулируют и переходят в
преследование в радиусе видимости — контакт запускает бой. Чем глубже регион,
тем больше порчи, врагов и их скорость.

**Переход в бой.** При столкновении — полуторасекундная сцена: камера
схлопывается, чёрные полосы, аристократ вытаскивает из-под фрака стол,
раскладывает сукно и карты. Это единственное заимствование у Undertale —
сам переключатель режима, не bullet-hell.

**Бой.** Пошаговый, вид от первого лица. Маны нет — лимит 5 карт за ход
(тяжёлые карты стоят 2 слота, карты-эффекты лимит поднимают).

- **Element** — вешает метку стихии. Вторая Element-карта другой стихии
  триггерит реакцию и снимает метку. 16 стихий, ~50 именованных пар
  (Огонь+Вода = Пар, Эфир+Тень = Разлом пустоты…), остальные 70 пар
  разрешаются процедурно в «Смесь»/«Разлад», так что мёртвых сочетаний нет.
- **Spell** — прямое действие: урон, залп, точный удар, вытягивание, лечение,
  усиление следующей реакции, подрыв метки.
- **Effect** — немагические статусы: щит, добор, +лимит карт, стан,
  сосредоточение, очищение, ослабление, регенерация.

**Противник.** Без колоды: HP-бар, фиксированный паттерн приёмов с телеграфом
на ход вперёд, многофазность (у боссов три фазы), разрушаемые уязвимые точки.
Разрушение точки, в зависимости от неё: выбивает приём из паттерна, оглушает,
навсегда открывает врага (+50% урона) или срывает его в следующую фазу.
С глубины 6 враг делает два действия за ход, с 12 — три; боссы на одно больше.

**Прицеливание** (открытый вопрос из ТЗ — решён гибридом). По умолчанию
автонаведение на корпус. `TAB`/правый клик берут конкретную точку: обычная
карта отдаёт по ней 65% урона и имеет 22% промаха, а «точные» карты
(`Pierce`, флаг `Precise` — в стартовой колоде это «Трость-шпага») бьют по
точке на 100% без промаха. Статус «Сосредоточение» убирает промах у любых карт.
Так ручное прицеливание — это осознанный риск, а отдельный тип карты — способ
его снять, без обязательного микроменеджмента.

**Прогрессия.** Материалы с врагов, боссов, ресурсных узлов и событий идут на
верстак: выковать новую процедурную карту, усилить (+уровень), мутировать
(аффикс + сдвиг чисел) или переплавить излишки. Успех решает мини-игра на
тайминг: ширина зелёной зоны равна шансу, а шанс жёстко ограничен 70% — внутри
есть узкая «идеальная» зона, она удваивает эффект. Провал мутации портит карту.
Карты генерируются процедурно: тип, стихия, числа по глубине, редкость
(6 ступеней), аффиксы и флаги Wild/Corrupted/Mutated/Precise.

**Мета-прогресс.** Уехавший на карете забег банкует все материалы и конвертирует
их в постоянный бонус к максимуму HP; смерть сохраняет только четверть.
Сохранение — `shichoy_meta.bin` рядом с .exe.

**Звук.** Ни одного аудиофайла. Шестнадцать «голосов стихий» и два десятка
эффектов синтезируются в память при старте из одной параметрической модели:
частотный свип, обертоны (от гармонических до несоизмеримых — так звучат
металл и кристалл), шум сквозь резонансный фильтр, треск, низкий подхвост.
Молния получает мгновенную атаку, резкий треск и раскат в хвосте; лёд —
звонкие несоизмеримые обертоны; земля — глухой удар с гулом. При розыгрыше
карты сперва слышен шорох бумаги, следом — голос её стихии; реакция бьёт
поверх обоих, и чем она сильнее, тем ниже её тон.

Музыка генеративная: орган, дрон, редкие колокола по пентатонике и ветер
считаются прямо в колбэке аудиопотока, поэтому трек не повторяется. Три
режима — меню, поле (почти шёпот) и бой (тише, но с низким пульсом вместо
колоколов) — переключаются по сцене с плавным переходом. `M` глушит всё.

**Языки.** Весь текст двуязычный (RU/EN), переключается в меню.

## Структура

```
src/
  core/Types.h      — enum'ы, билингвальные строки, ГПСЧ, цветовые утилиты
  core/Content.*    — 16 стихий, таблица реакций, статусы, материалы, пулы имён
  core/Cards.*      — карта, процедурная генерация, мутации, апгрейд, колода
  audio/ProcAudio.* — синтез эффектов и генеративная музыка, тоже без файлов
  art/ProcArt.*     — палитра Таро, шрифты, шум, орнаменты, сигилы, рисование
                      карт, героя и врагов — весь визуал игры
  world/Overworld.* — генерация региона, сущности, движение, ИИ врагов, отрисовка
  combat/Enemy.*    — паттерны, фазы, уязвимые точки, генерация противника
  combat/Combat.*   — конечный автомат боя, метки, реакции, урон, статусы, лут
  craft/Craft.*     — инвентарь, планы крафта, мини-игра на тайминг
  app/Game.*        — сцены, переходы, диалоги, HUD, меню, кодекс
  app/GameCombatUI.cpp — интерфейс боя и экран наград
  main.cpp          — точка входа, --selftest, --shot
```

## Куда двигаться дальше

- **Арт.** Кодовая графика работает и её достаточно, чтобы играть. Если
  захочется растровых спрайтов — заводится папка `assets/` и подменяется
  вызовами `DrawTexture` в `ProcArt`; остальной код не меняется. Бесплатные
  CC0-источники под эту эстетику: Kenney.nl, OpenGameArt (метка CC0),
  itch.io с фильтром «free assets», LPC-набор.
- **Звук.** Сейчас у врагов нет собственных голосов: приёмы звучат общим
  ударом. Стоит дать каждому противнику тембр от его стихии — модель для
  этого уже есть, нужен только набор параметров на приём.
- **Контент.** Именованных реакций сейчас ~50 из 120 возможных пар; остальные
  закрыты процедурным фолбэком, их можно постепенно расписывать вручную.
- **Баланс.** `--selftest` даёт быстрый замер: сейчас случайная игра выигрывает
  ровно половину боёв на глубинах 1–15, то есть у осмысленной игры запас есть,
  а глубина всё равно наказывает.
